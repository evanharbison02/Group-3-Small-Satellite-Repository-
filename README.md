 # Group 3 Small-Satellite Repository 

A repository for the system code for group 3 of WVU's Small Satellite team **Zenith**, following the [CubeSat standards].

It's publicly viewable for anyone looking for inspiration when writing their own satellite's source code. Please note that only members of **Zenith** can contribute directly to this repository. For more information we wellcome you to view our [wiki]. 

Zenith would like to extend our thanks to the [WVU School of Art and Design] for their partnership and for designing our professional team logo. Their creativity and talent helped give our team an identity we’re excited to represent
